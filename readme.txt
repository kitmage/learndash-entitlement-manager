Manage LMS entitlements for Aspen.

== Description ==

Aspen LMS Entitlement Manager is an empty plugin scaffold ready for development.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate Aspen LMS Entitlement Manager through the **Plugins** screen in WordPress.
